    The manual

    Your whole backend, on one rack.

    Backplane sets up the plumbing a business runs on (payments, a database, email, file storage and a little server code) across the services you already use, then keeps proving it all works.

    01Start here

    Most businesses need the same pieces wired together: take a payment, record the order, send the receipt, deliver the file, keep customers' data private. Doing that across five dashboards is where things quietly break.

    Backplane does it from one place. You pick a preset for your kind of business (or describe it in plain words), read a plain-English work order, approve it, and Backplane builds every piece in the right order. Then it tests every connection, including a real test purchase where nothing is charged.

    Built on
    CloudflareSupabaseStripeResendGitHub

    Everything runs in your own accounts. You own it, and you can export it any time.

    02Install & first launch

    1. Double-click Install Backplane.exe. If Windows says “Windows protected your PC”, choose More info → Run anyway. Backplane isn't code-signed yet, so SmartScreen doesn't recognise it.
    2. Click through Setup. No administrator password is needed: Backplane installs for your Windows account only, in %LOCALAPPDATA%\Programs\Backplane.
    3. Open Backplane. A six-page welcome guide explains the basics and ends with a choice: Practice first or Set up a real backend.
    Backplane draws its window with Microsoft Edge WebView2, which Windows 11 and most Windows 10 PCs already have. If yours doesn't, Setup offers Microsoft's free download; until it's installed, Backplane opens in your web browser instead and works the same way.

    03Practice on the Bench

    The Bench is a practice sandbox. It starts pretend versions of Cloudflare, Supabase, Stripe, Resend and GitHub inside Backplane, with practice accounts already connected, so you can run a complete build and certification without signing up for anything.

    • Break things on purpose. Delete a bucket, disable a webhook or turn off row-level security, then watch Backplane notice, explain what broke, and repair it.
    • Nothing real is touched. Practice backends live only on the Bench and are cleared when you start or stop it.
    • It works offline.

    04Connect your accounts

    Open Accounts → Connect an account. Each provider has a short guide that opens the right page, with the permissions pre-selected where the provider allows. All five have free tiers that cover a new business.

    ServiceWhat it does for you
    CloudflareRuns your backend code (a Worker), private file storage, and your domain's DNS.
    SupabaseYour database, customer sign-in and row-level security.
    StripeCheckout, subscriptions, refunds, and payment notifications.
    ResendReceipts and notification email from your own domain.
    GitHubA private repository for the generated code, deployed automatically.

    Presets can also link add-ons for single jobs: text messages (Twilio), error monitoring (Sentry), analytics (PostHog), media (Cloudinary), caching (Upstash), hosting (Vercel) and enterprise sign-in (Clerk). Add-ons are connected and watched as part of your backend's health; Backplane doesn't create anything inside them yet, and the app says so.

    Each connection is checked right away: is the key valid, is it the right account, does it have the permissions Backplane needs.

    05Build a backend

    This really is a sequence, and Backplane never skips a step.

    1. Describe. In Backends → New backend, pick a preset by kind of business, or describe what you need in plain words. Answer a few questions: price, domain, what customers receive.
    2. Review the work order. Backplane reads what already exists and lists exactly what it would create or change, why, and an honest cost estimate. Nothing has happened yet.
    3. Approve & build. Steps run in dependency order, with retries and a checkpoint after each one. If a step fails, fix the cause and press Resume: finished steps aren't repeated. A finished build can be rolled back.
    4. Certify. Six levels of checks, from “is the key valid” to a full test purchase that is cleaned up afterwards.
    5. Monitor. Checks keep running on a schedule, and you're told the moment something changes.

    Describing it in your own words

    Backplane matches your description to a preset on this PC, with no internet needed. If you add your own Anthropic API key in Settings, the optional Claude assistant can suggest a better fit. It receives only the description you typed (never your keys or project data), and it can only suggest: you still review and approve the plan.

    Environments

    Each backend can have development, staging and production environments, kept separate. Production is protected: deleting or rolling it back asks you to type the project name, and live Stripe keys are refused anywhere else.

    Already have a setup?

    Backends → Import existing adopts resources you built elsewhere so Backplane can watch them. Imported backends are watched, never changed.

    06The six checks

    Every connection is proven, not assumed. Quick checks run levels 1–4 and never write anything. Full certifications run all six, using clearly marked test records that are removed afterwards. No card is ever charged.

    L1
    Provider connectionKeys are valid, the right account, the permissions Backplane needs, APIs reachable.
    L2
    Resources existEverything that was built still exists; nothing deleted or renamed outside Backplane.
    L3
    Configuration matchesLive settings match what was set up: bindings, secrets, webhooks, row-level security, email DNS.
    L4
    Connections workThe Worker really reaches the database, storage and email; Stripe really delivers to the Worker.
    L5
    Functions workEach function works with safe test data: write and read a row, store and fetch a file, send to a test inbox, sign in a test user.
    L6
    End-to-end journeyThe whole customer journey, e.g. a signed test purchase through checkout, order, download link and email, then everything is cleaned up.

    Reading the result

    StatusMeans
    FULLY OPERATIONALA full certification passed, including the end-to-end journey.
    OPERATIONALEverything checked is healthy (a quick check, or a backend without a journey test).
    NEEDS ATTENTIONIt works, but something needs you, such as a product file not uploaded yet.
    DEGRADEDSomething failed, but the core of the business still works.
    BROKENA critical piece failed. Customers are affected; the fix is shown first.
    NOT BUILT YETNothing to check until the first build.

    08Monitoring & alerts

    • New backends get a quick check every 30 minutes and a full certification once a day, plus a full check after every build. Change the schedule per backend on its Settings tab.
    • When a status changes, Windows shows a notification.
    • Background checks while Backplane is closed are off until you turn them on in Settings. They add an hourly Windows task named “Backplane Monitor”, with no administrator rights needed.
    • Backplane also watches the providers themselves: when an API it uses announces a change or retirement, it's listed with its date under Settings → Provider changes.
    • Register is one log for every build and check across all providers, with keys and secrets scrubbed out.

    09When something breaks

    If something changes outside Backplane (a deleted bucket, a disabled webhook, row-level security switched off, an expired key), the next check says:

    • what broke, in plain English, and when;
    • what's affected (“Download delivery”) and, just as important, what still works;
    • the safe fix. Repairs go through the same work order and approval as a build, so you see exactly what will change.

    To see how far a problem reaches, open the backend's Rack tab and click a unit or a patch cord. Like a cable tracer's tone, the path lights up downstream and stops at the first fault.

    10Your code

    For backends that need server code, Backplane writes it for you and shows it on the Code tab. Every file is marked:

    GENERATEDWritten by Backplane; updated when you change the backend.
    USER MODIFIEDYou changed it. Backplane never overwrites it without asking.
    SYSTEM CONFIGDeployment settings Backplane keeps in step with what it deploys.

    With GitHub connected, the code goes to a private repository and deploys automatically on every change. You can also export a backend at any time: its manifest, code, a Wrangler config and an OpenTofu starting point.

    11Safety & secrets

    • Keys stay on this computer, encrypted by Windows for your account. They're never written to project files, exports, generated code or logs.
    • Nothing happens without a plan you approve. The assistant only suggests; it never builds or deploys.
    • Production is protected. Destructive steps ask you to type the project name.
    • Test data is cleaned up. Certification uses marked probe records, test inboxes and expired checkout sessions.
    • You're not locked in. Export any backend whenever you like.

    12Look & feel

    Every theme is a material from real rack gear: Rack (black anodized), Aluminum (brushed, daylight), Bench (ESD mat, probe blue), Copper, Fiber (aqua at night), High contrast, and System, which follows Windows light or dark. The swatches at the top of this page switch this guide too.

    In Settings you can also change the text size and density, turn off motion (no blinking LEDs or cable tone), and show advanced options everywhere.

    13Uninstall & your data

    Run Uninstall Backplane.exe from the download folder, or open Settings → Apps → Installed apps → Backplane → Uninstall.

    • Uninstalling does not remove what Backplane built in your Cloudflare, Supabase, Stripe, Resend or GitHub accounts. To remove those, open the backend and use Settings → Tear down first.
    • You choose whether to keep your Backplane data (backends, history, saved connections) for a reinstall. It lives in %APPDATA%\Backplane.
    • The background task, notifications registration and shortcuts are always removed. Exports in Downloads\Backplane exports are yours and stay.

    14Troubleshooting

    Windows says it protected my PC

    Choose More info → Run anyway. To confirm the download is intact, compare Get-FileHash ".\Install Backplane.exe" in PowerShell with SHA256SUMS.txt.

    Backplane opened in my browser

    The WebView2 Runtime is missing. Install it from Microsoft (direct download) and reopen Backplane. Everything works the same in the browser meanwhile: a small Backplane box stays open while you work, and choosing OK in it quits Backplane.

    Nothing happens when I open it again

    Backplane is already running; the existing window comes to the front. Check the taskbar.

    A step failed during a build

    The card under the progress bar says what went wrong and how to fix it. Fix the cause, then press Resume. Steps that already finished aren't repeated.

    Still stuck?

    Open Register, filter to the backend, and include what it shows when you write to support. The log is already scrubbed of keys.
